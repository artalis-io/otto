# Solomon VRPTW Benchmark Cases

This directory contains the canonical 100-customer Solomon VRPTW instance files
(`C*`, `R*`, and `RC*` classes) used by `surge/benchmarks/bench_solomon.c`.

Source used for import:
- https://github.com/iRB-Lab/py-ga-VRPTW (`data/text/*.txt`)

These files originate from the Solomon (1987) benchmark set for VRPTW.
