# Documentation Audit Skill

Audit OTTO documentation for organization, consistency, and completeness. Find dangling .md files that should be consolidated into the central docs/ structure.

**Arguments:** $ARGUMENTS (optional: specific directory or "full" for complete audit)

## Usage

```
/docs-audit                  # Quick audit - find dangling .md files
/docs-audit full             # Full audit with consolidation plan
/docs-audit <module>         # Audit specific module (e.g., /docs-audit ralph)
```

## Files That Should Stay in Component Directories

These files are component-specific and should NOT be moved to docs/:

| File Type | Purpose | Location |
|-----------|---------|----------|
| `CLAUDE.md` | Claude Code instructions per module | `<module>/CLAUDE.md` |
| `README.md` | Module setup/usage | `<module>/README.md` |
| `AGENTS.md` | Multi-agent development patterns | `<module>/AGENTS.md` |
| `CONTRIBUTING.md` | Contribution guidelines | `<module>/CONTRIBUTING.md` |
| `MANIFESTO.md` (ClayShards) | Points to main docs/MANIFESTO.md | `clayshards/clay-shards/MANIFESTO.md` |

## Files That Should Be Consolidated

### Move to docs/roadmaps/

| Pattern | Action |
|---------|--------|
| `**/TODO.md` | Merge into `docs/roadmaps/<module>.md` |
| `**/TODOS.md` | Merge into `docs/roadmaps/<module>.md` |
| `**/TODO_FEATURES.md` | Merge into `docs/roadmaps/<module>.md` |
| `**/PERFORMANCE.md` | Merge into `docs/roadmaps/<module>.md` |
| `**/*_ROADMAP.md` | Merge into `docs/roadmaps/<module>.md` |

### Move to docs/internals/

| Pattern | Action |
|---------|--------|
| `**/ARCHITECTURE.md` (module-specific) | Move to `docs/internals/<module>-architecture.md` |
| `**/DESIGN.md` | Move to `docs/internals/<module>-design.md` |
| Technical reference docs (e.g., algorithm explanations) | Move to `docs/internals/` |

### Move to docs/archive/

| Pattern | Action |
|---------|--------|
| `**/PLAN_*.md` (completed) | Archive to `docs/archive/<module>/` |
| `**/*_PLAN.md` (completed) | Archive to `docs/archive/<module>/` |
| `**/*_IMPROVEMENTS.md` (completed) | Archive to `docs/archive/<module>/` |

### Gitignore (Generated Files)

| Pattern | Reason |
|---------|--------|
| `**/AUDIT_REPORT*.md` | Generated by audit skills |

## Audit Procedure

### 1. Find All .md Files

```bash
# Find all .md files outside docs/ that aren't README.md, CLAUDE.md, or AGENTS.md
find . -name "*.md" -type f \
  ! -path "./docs/*" \
  ! -path "./.claude/*" \
  ! -path "./vendor/*" \
  ! -name "README.md" \
  ! -name "CLAUDE.md" \
  ! -name "AGENTS.md" \
  ! -name "CONTRIBUTING.md" \
  ! -name "MANIFESTO.md"
```

### 2. Categorize Each File

For each found file, determine:

1. **Keep in place**: Component-specific docs (see above)
2. **Merge to roadmaps**: TODOs, performance plans, feature lists
3. **Move to internals**: Technical reference, design docs
4. **Archive**: Completed plans, historical docs
5. **Delete**: Redundant, superseded by other docs

### 3. Check for Stale Content

- Files not modified in >6 months that describe "planned" features
- Duplicate content across multiple files
- References to deleted code/features

### 4. Verify Cross-References

- Check that archived files aren't referenced from active docs
- Update links in CLAUDE.md, README.md when files move
- Verify docs/roadmaps/README.md lists all roadmaps

### 5. Generate Report

```markdown
## Documentation Audit Report

**Date:** YYYY-MM-DD
**Files Scanned:** N

### Dangling Files Found

| File | Lines | Recommendation |
|------|-------|----------------|
| `ralph/PLAN_FOO.md` | 150 | Archive to docs/archive/ralph/ |
| `velo/PERFORMANCE.md` | 300 | Merge into docs/roadmaps/velo.md |

### Actions Required

1. **Merge to roadmaps/**
   - [ ] `module/TODO.md` → `docs/roadmaps/module.md`

2. **Move to internals/**
   - [ ] `module/DESIGN.md` → `docs/internals/module-design.md`

3. **Archive**
   - [ ] `module/PLAN_*.md` → `docs/archive/module/`

### Cross-Reference Updates

- [ ] Update CLAUDE.md documentation links
- [ ] Update README.md documentation table
- [ ] Update docs/roadmaps/README.md
```

## Consolidation Workflow

When consolidating files:

### 1. Create New Roadmap (if needed)

```markdown
# <Module> Roadmap

Development roadmap for <Module> covering <brief description>.

## Status Summary (Date)

| Area | Status | Key Files |
|------|--------|-----------|
| **Feature A** | ✅ Complete | `file.c` |
| **Feature B** | ❌ TODO | - |

---

## Chapter 1: <Topic>

### 1.1 Completed

...

### 1.2 TODO

...
```

### 2. Archive Source Files

```bash
mkdir -p docs/archive/<module>
git mv <source> docs/archive/<module>/
```

### 3. Update References

- CLAUDE.md: Update Documentation Structure section
- README.md: Update Documentation table
- Component CLAUDE.md: Update Related section if it referenced moved files

### 4. Clean Up Empty Directories

```bash
rmdir <module>/docs/  # If now empty
```
